Nuro: foreground media playback

Version 1.3.1 · build 29 · Android 36

This continuous recording demonstrates the user-initiated Qur’an recitation feature that uses FOREGROUND_SERVICE_MEDIA_PLAYBACK.

  1. Open a surah from the Qur’an list.
  2. Tap Listen to start recitation.
  3. Return to the Android home screen and open system media controls. Recitation continues in the background.
  4. Pause, resume and stop using the Android media controls.

The service starts when the user starts playback. Interrupting it would stop the recitation when the user leaves the app. Playback is visible through Android media controls and can be stopped by the user.

Recorded from the actual production APK (com.mnpekdemir.dhikrflow) in a dedicated test emulator, without a personal account or user records. This screen recording has no system-audio track; the active media session and foreground-service state were separately verified during the recording.
