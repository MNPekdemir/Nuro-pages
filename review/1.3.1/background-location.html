Nuro: travel-aware prayer times

Version 1.3.1 · build 29 · Android 36 · Production APK

Optional background location keeps home screen prayer widgets and enabled prayer alerts relevant when a user travels, without requiring the app to remain open. The user enables Follow location while travelling in Prayer settings.

  1. Read Nuro’s prominent disclosure before granting background access.
  2. Open Android Settings and choose Allow all the time.
  3. With the Nuro UI closed, the home screen widget changes from Fatih (Istanbul) to Altındağ (Ankara) and recalculates prayer times.

Test method: Recorded on a dedicated Android emulator using synthetic Istanbul and Ankara coordinates, without personal user data. This short video joins actual recording segments and speeds up Settings navigation for pace. The app process is terminated normally in the background (not force-stopped). Android’s standard JobScheduler test dispatch runs the existing production periodic location job to avoid waiting for its system-controlled schedule. No app UI is opened for the final widget update.

On real devices, Android controls delivery timing. Passive movement updates are throttled and periodic work may be delayed by battery restrictions; an immediate update is not guaranteed. Force-stopping an app prevents its background work until the user opens it again. Nuro does not continuously poll GPS.
